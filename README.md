# LeetCode Solutions

My solutions to [LeetCode](https://leetcode.com/) problems, organized one folder per problem.

## 📁 Structure

Each problem lives in its own folder, named `<problem-number>-<problem-slug>`:

```
leetcode-solutions/
├── 0001-two-sum/
│   ├── solution.* 
│   └── README.md (optional notes / approach)
└── ...
```
